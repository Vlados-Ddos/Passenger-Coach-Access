# Passenger Coach Access

A mod for Passenger Jobs: approach the side door of a passenger coach and aim directly at the door. Only then will the prompt with the assigned key appear.
The player will be moved directly behind the selected side door and properly attached to the moving coach.
Pressing the key again exits through the side door.

Through an end door, you can only move directly into the adjacent coupled passenger coach.
Free end doors are not entry or exit points.

The key and activation distance can be changed in the Unity Mod Manager menu (`Ctrl+F10`).

## Multiplayer

When Multiplayer is active, the mod automatically registers through its API as required for all session participants. Therefore, the host and every client must have Passenger Coach Access enabled; this prevents a client without the mod from joining and desynchronizing coach access. For predictable behavior, use the same mod version for all players.

No Passenger Jobs data is modified: coach types are determined through its registered passenger cargo, and player movement uses the game's built-in mechanism for players on a moving train.

# Passenger Coach Access

Мод для Passenger Jobs: подойдите к боковой двери пассажирского вагона и наведите прицел
прямо на дверь. Только в этом случае появится подсказка с назначенной клавишей.
Игрок переместится сразу за выбранную боковую дверь и штатно прикрепится к движущемуся вагону.
Повторное нажатие выводит через боковую дверь.

Через торцевую дверь можно перейти только прямо в соседний сцепленный пассажирский вагон.
Свободные торцевые двери не являются точками входа или выхода.

Клавишу и расстояние активации можно изменить в меню Unity Mod Manager (`Ctrl+F10`).

## Мультиплеер

При активном Multiplayer мод автоматически регистрируется через его API как обязательный для всех
участников сессии. Поэтому хост и каждый клиент должны иметь Passenger Coach Access включённым;
это не даёт клиенту без мода подключиться и рассинхронизировать доступ в вагон. Для предсказуемого
поведения используйте одинаковую версию мода у всех игроков.

Никакие данные Passenger Jobs не изменяются: типы вагонов определяются через его зарегистрированный
пассажирский груз, а перемещение игрока использует штатный механизм игры для игроков на движущемся составе.
